# UniGeek 1.9.5
*2026-11-19*

The RF-kit bring-up lands for diy_joystick: CC1101 on its own SPI bus, NRF24L01+ wired on a dedicated SPI3 bus, the multi-module 2.4 GHz jammer, and the IR universal-remote arsenal — Instant Off / Quick Off / Find Code / Power Blast / Brand Zap with the full Flipper universal-TV table. Brute Force gets a hot-zone sweep engine. Games ship as the original full-screen TFT builds on diy_joystick (native LVGL versions stay for other boards), and the display pipeline keeps the full-screen PSRAM draw buffer for ~30 fps UI. Plus three hard crashes fixed — including the Sub-GHz use-after-free that rebooted the device on screen open.

## diy_joystick: RF kit wiring

> **CC1101 — its own HSPI bus**
> CC1101 (CS=10, GDO0=9) rides HSPI SCK=12 / MOSI=11 / MISO=13. Every CS is asserted high at boot, unused CE lines low. Grove I2C moved to GPIO3/45. Joystick re-enabled (JOYSTICK_NOT_WIRED removed — the stick is soldered on this board now).

> **NRF24 — dedicated SPI3 bus (SCK=18 / MOSI=17 / MISO=16)**
> The NRF24L01+ bank no longer shares the CC1101 bus: `Device` gained a second `ExtSpiClass` on SPI3, brought up on GPIO18/17/16, and every NRF path (detect, spectrum, jammer, MouseJack) goes through it, falling back to the shared bus on boards without one. CE/CSN pads: N1 = 5/6, N2 = 7/15 (GPIO16–18 are the bus now and are never toggled as CE/CSN). The screen auto-detects the module position with retries, then runs a raw STATUS-register scan across every CE/CSN pad — including a pass with MOSI/MISO exchanged and a GPIO17↔GPIO16 loopback probe — so a mis-wired or mirrored adapter is named precisely instead of a bare "not detected".

## New Features

> **Games: original full-screen TFT on diy_joystick, native LVGL elsewhere**
> Flappy, Memory Sequence, Number Guess, Wordle (EN/ID), Decoder, Fishing and Quenswer ship on diy_joystick as the original TFT builds, filling the whole 320×240 panel — no header bar, no side strip, `GAME_TFT_CANVAS` gates them ahead of the LVGL shell. Boards with a native LVGL shell keep the pure-widget rewrite (rounded cells, overlay panels, theme accents, stick-only input). The Decoder game accepts digits 0–9 only in both paths — the letters A–F are gone.

> **~30 fps UI: full-screen LVGL draw buffer**
> The LVGL draw buffer was 40 rows — every full-screen redraw took eight SPI passes (~13 fps). Now it is a full-screen buffer in PSRAM: one pass per frame. Shell restores, game overlays and list pages all move at display speed.

> **NRF24 Jam All (4×)**
> Every nRF24L01+ parks on a constant carrier (CONT_WAVE, max PA) and the modules sweep the 2.4 GHz band interleaved — four channels jammed at any instant, the full 126-channel band revisited every ~13 ms. Own FreeRTOS task on core 0 so the sweep rate is independent of the UI. Status panel shows online modules and hop rate. Falls back to a single-module sweep on boards without the module bank.

> **IR Instant Off / Quick Off / Find Code**
> Instant Off: one press fires a 62-code net (top brands + the ODM addresses DEXP/Vestel/Realtek boards use) — any TV or projector in ~6 s, no setup, no dialogs. Find Code: the universal sweep runs in ~25-code bursts; pressing the stick the moment the TV dies saves that window to config. Quick Off then replays the saved window first — your own TV dies in ~1 s from then on. Achievements included.

> **IR Power Blast — 3,952-signal universal dump**
> Two modes: Fast (475 curated codes) and All Devices — the full open POWER-off arsenal: 1,552 protocol-encoded codes (NEC/NECext, Samsung36, SIRC 12/15/20, RC5/RC6, JVC, Sharp, Mitsubishi, Kaseikyo) harvested from IRDB + Flipper-IRDB, plus 2,401 raw waveform captures from Flipper's universal Power_off.ir replayed from PROGMEM. Covers TVs, projectors and ODM boards the branded lists miss. 4 MB boards get the Fast table only (the 390 KB dump would overflow their app partition).

> **Sub-GHz Brute Force: hot-zone sweep engine**
> Repeats default 3→1 (receivers decode the first frame; 3× throughput) and the sweep order is now likelihood-based: low serials + all-off DIP (0x000–0x0FF), famous factory/service patterns (0xAAA, 0x555, 0x0AAAAA…), all-on DIP descending, then the remainder. A 12-bit protocol covers its hot zones in seconds instead of minutes; 24-bit spaces hit DIP/factory defaults fast instead of being hopeless. The panel shows live rate and the active zone.

> **IR Brand Zap — brand-scoped volley v2: 119 brands + built-in remote keys**
> The brand library is now the full IRDB TV catalog (108 brands — Samsung, LG, Sony, Panasonic, Philips, Hisense, TCL, Toshiba, Sharp, RCA, Grundig, Telefunken, Thomson, Xiaomi, Haier, BBK, Blaupunkt, Supra, Erisson, Mivar, Finlux, Medion, Loewe, Pioneer, Westinghouse, Zenith…) plus 11 projector brands (Epson, BenQ, Optoma, Sony, NEC, Acer, ViewSonic, LG, InFocus, JVC, Xiaomi), and a synthesized DEXP entry built from the verified Vestel-ODM NEC 0x0 zone. Picking a brand now opens a command panel: POWER OFF, POWER ON, MUTE, VOL+, VOL- — a brand-scoped universal remote, not just a killer. 672 protocol-encoded codes in total. The volley stays non-blocking (one code per frame, live progress, BACK cancels). Kaseikyo (Panasonic/Grundig) and RCA are reconstructed bit-exact; the shared IrEmit engine backs Power Blast and Brand Zap alike.

> **IR UNIVERSAL TV — the Flipper `tv.ir` remote, embedded**
> The first entry of the brand picker is now UNIVERSAL TV: 111 TV models generated straight from Flipper Zero's `tv.ir` (parsed, deduplicated, raw samples clamped to the 48 kHz capture window), each model carrying Power / Mute / Vol+ / Vol− / Ch+ / Ch−. One key press fires the whole model's code for that command — the same approach Flipper uses, and the reason it works on sets no brand list covers. Tables sit behind `#ifndef BOARD_4MB` (4 MB builds keep the fast tables). IrEmit gained NEC42, RC5X and PIONEER branches for the protocols `tv.ir` uses.

> **IR emit pacing — the DEXP fix**
> Brand Zap and UNIVERSAL TV used to double-frame every NEC code with a 40 ms gap; Vestel/DEXP decoders discard those as noise. Now a single frame plus a 15 ms gap (Instant Off's proven cadence), RC5/RC6 still doubled, raw codes sent once with a 40 ms tail. That is what makes POWER work on DEXP-class budget sets.

> **Instant Off: Turbo volley — ~3× faster TV shutdown**
> The instant window now fires single-frame shots (receivers latch on the first frame — the second one was repeat insurance) with 15 ms gaps instead of the old frame+repeat+95 ms cadence: the whole 67-code volley drops from ~15 s to ~5.5 s. Bi-phase RC5/RC6 still double up — their decoders genuinely need two frames. The table is re-ordered likelihood-first and widened with IRDB multi-model powers: the DEXP/Vestel ODM NEC 0x0 zone (the bulk of budget TVs) leads, then universal NEC plus Toshiba/Hisense/TCL/LG classics, Samsung (both generations), Sony, Philips, Panasonic, RCA, then the exotic JVC/Mitsubishi tail. A saved Quick Off window still replays first when set.

## Fixes

> **Sub-GHz screen reboot loop: LVGL use-after-free in ProgressView**
> Opening the Sub-GHz (CC1101) screen panicked with LoadProhibited before the radio was even touched. ProgressView is a singleton that outlives screens: the progress panel was deleted together with its parent screen, leaving dangling pointers, and the next `init()` called `lv_obj_del()` on freed memory (`lv_obj_get_screen` ← `lv_obj_del` ← `_teardown` ← `SubGHzScreen::onInit`). Every panel access is now guarded by `lv_obj_is_valid()` — a panel that went away with its screen is dropped and rebuilt, and pointers are nulled unconditionally in `init`, `progress` and `finish`.

> **NRF24 "not detected" lie after a successful probe**
> The screen probed the radio, then probed it again for a sanity check — on a marginal daisy-chained bus the second `begin()` failed and the screen reported "not detected" even though the module had answered. Removed; detection now retries three times per position and keeps the module it found.

> **IR blocking loops: BACK works again + no more heap corruption**
> TV-B-Gone / Power Blast / Find Code loops now drain the USB remote (UartFM.poll) and pump LVGL between codes. Two crash causes removed: the progress callback updated the LVGL label on every single code (thousands of mutations with no pump corrupted the widget heap — coredump showed lv_obj_construct on a garbage pointer); and remote-keyboard BACK never reached the firmware because the loops never read the USB stream.

> **Legacy boards: LogView builds again**
> LogView used `_dirty` in shared inline methods but declared it only inside its USE_LVGL_SHELL block — every non-LVGL board failed to compile since the 1.9.4 port. Declared unconditionally.

> **Mascot picker crash (1.9.4) extended**
> All remaining uninitialized InputSelectAction option stacks zero-initialized (16 files beyond the Settings → Mascot fix).
