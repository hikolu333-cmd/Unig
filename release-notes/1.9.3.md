# UniGeek 1.9.3
*2026-11-16*

The radio subsystem is rebuilt around **on-demand power**: no boot-time warm-up, no session-long keep-alive — the modem powers up only when a WiFi/BT feature needs it and powers back down when the app releases it. Plus an N16R8 memory fix and a slimmer serial console.

## New Features

> **RadioKeeper: on-demand radio (diy_joystick)**
> The v1.9.1/v1.9.2 strategy (one-shot warm-up at boot + radio never powering down) kept the modem hot for the whole session and punished healthy boards with a clocked-down warm-up. The rework powers the radio up only on demand — idle boards stay cool — while keeping the weak-rail insurance at zero cost for healthy hardware: every `esp_wifi_start()` is wrapped with an NVS "attempting" flag so a mid-start brownout is recognized and counted by the next boot; after 5 counted failures per power cycle starts are refused with `ESP_ERR_WIFI_STATE` and WiFi screens report an error instead of reboot-looping; once a weak rail is detected the RF calibration is downgraded to `PHY_RF_CAL_NONE` to dodge the PA calibration spike. Healthy boards always get full calibration for accurate TX.

> **N16R8 modules: octal PSRAM (diy_joystick)**
> The board build now targets the ESP32-S3 N16R8 (16 MB QIO flash + 8 MB octal PSRAM): `memory_type qio_opi` and `BOARD_HAS_PSRAM` restored. The v1.9.0 "PSRAM assumption removed" fix was for a no-PSRAM module revision — both are now supported by picking the right manifest for your module.

## Fixes

> **Serial console no longer eats File Manager / Remote bytes**
> The v1.9.x PC Remote hook consumed every byte arriving on the native USB console, which could swallow frames belonging to the USB File Manager and Remote protocols (ctx `F`/`S`). The service console now accepts only the radio re-arm key `r`, and on the native USB side it is taken with `peek()` so protocol bytes are never consumed.

## Removed

> **PC Remote + UART screen-mirror dev tooling**
> The single-character PC Remote keys (WASD/Enter/Backspace/H), the chip-telemetry key `t` and the development screen-mirror stream over UART0 were bring-up aids for a bench board without a panel or stick, and are gone from the release build. UART0 (the bridge console that survives radio power-up) stays, now at 115200, carrying RadioKeeper telemetry and the `r` service key. The proper remote with a live screen mirror is the browser Remote Access page / Android app.
